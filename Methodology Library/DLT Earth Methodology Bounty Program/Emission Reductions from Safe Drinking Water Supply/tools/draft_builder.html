VMR0015 Draft Builder

Guardian gives each schema a new ID on every import, so a sample file only loads after its header matches your policy. This page copies the header from your blank draft onto the sample. Nothing leaves your computer.

1. Your blank draft from Guardian

Open the form in Guardian, click Save draft (or download the draft) without filling anything, and choose that file here.

2. The matching sample file

From sample-data/: PP account → 1_…, VVB account → 2_…, Project Description → 3_…, Monitoring Report → 4_…, Validation Report → 5_…, Verification Report → 6_…, VCU Issuance Request → 7_….

3. Build and download

Load the downloaded file into the form in Guardian with Load draft, check the fields listed in the Form Filling Guide, then submit.
