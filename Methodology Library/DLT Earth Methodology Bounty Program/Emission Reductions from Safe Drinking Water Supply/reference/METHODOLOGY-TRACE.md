# VMR0015 v3.1: methodology trace

**Where things live in the policy:**
- **Math blocks:** **PD** = `pp_err_calculation_pd_vcs_ex_ante` (ex-ante); **MR** = `pp_err_calculation_mr_vcs_ex_post` (ex-post).
- **Declarative formulas:** names in the form `eqXXX`.
- **Code:** the code part of the same math block. No calculation is in customLogic; the 5 customLogic blocks only refuse invalid actions.
- **Inputs:** schema paths. A2.1 = `appendix2.a21_*` (fixed at validation, read from the registered PD); A2.2 = `appendix2.a22_*` (monitored).

**Where the cites come from:**
- **Page cites:** each row gives the page, paragraph, table or equation number in the published PDF (AMS = AMS-III.AV v09.0, VMR = VMR0015 v1.0, and the tool's own version). Check those against the PDFs.
- **Ids in brackets** (EQ-…, M…, V…, B…, C…, and "eq.csv") are the identifiers of the equation list and manual check log of the earlier v3 build. Those working files are not part of this package; the page and equation numbers are what to check.
- **Tests:** `tools/regression.py` (60 cases on these files; among them, three added after the 19 October review cover fNRB with no value for its option, fNRB option 1 from the UNFCCC value, and a negative ex-ante estimate, run on Guardian's own math engine from `tools/guardian_math/`). The 19 October audit re-checked every row against the text.
- **Declared functions:** the core equations are also formula functions in both mathBlocks (`fnBE`, `fnFuel`, `fnQPW21`, `fnQPW22`, `fnCap`, `fnPE`, `fnER`, `fnM`, `fnFNRB2`, `fnXboil`, `fnEtaWb`, `fnVT0008F`, `fnSampN`, `fnDisc`); the code calls them for every value it uses and flags any disagreement.

## Round 4 template trace (schemas)

The template text files and build scripts named in this section belong to the earlier v3 working tree and are not in this package. The templates are Verra's published VCS v5.0A/v5.0B PD, MR, Validation Report and Verification Report templates; the scripts used for v3.1 are in `tools/template_build/`, and `tools/audit/tpl_strict.py` checks every template label against the schemas.

- Validation 3.1.4.x, 3.1.14.x, 3.1.15.x, 3.1.17.x, 3.2.x, 3.3.x, 3.4.2.x: `34_VCS_Validation_Report_Template_v5.0A.txt` (parser `build/scripts/valparse.py`, builders `step14b_val.py`, `step14c_val32.py`).

## Round 5 additions

- Eq.(1) (VMR0015 p.7): the same `BL_fuel,i x (EF_CO2 x fNRB + EF_nonCO2)` term is applied to every baseline fuel row and Adj_LE multiplies the sum (PD and MR math blocks, function `fuelTerm`, `adjLE`). The independent implementation in `tools/regression.py` sums over every baseline fuel row; a two-fuel case (wood and charcoal) is tested.
- Sampling standard v09.0 para 18(b)-(c) (PDF p.9): discount `3 x (attained - target)` only for survey years 1-2 and attained precision 90/15 or better, else ER = 0 with a flag (MR math block, `surveyYearInCP` on each sampling record).
