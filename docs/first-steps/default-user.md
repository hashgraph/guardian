# First steps \[Default User]

The Hedera Guardian is an open source platform for issuing, verifying, and managing digital environmental assets. The "Default User" account type signs up as an account under a "Standard Registry" and can perform actions on published policies such as submit project documents or search for policies.&#x20;

To get set up, you must first have a Standard Registry administrator grant policy permissions to your user.&#x20;

In the future, this section will be expanded upon to better support new users.
