# Hedera

Hedera is the section of Guardian where you manage the network-level resources — tokens, contracts, and relayer accounts — that a published policy relies on to mint, transfer, and retire digital environmental assets on the Hedera network.

### Reference

* **Tokens** — fungible or non-fungible tokens created through the Hedera Token Service, with configurable Admin, Supply, Freeze, KYC, and Wipe permissions.
* **Contracts** — includes Token Wiping Contracts and Token Retirement Contracts, that together handle permissioned, atomic retirement of tokens.
* **Relayer Accounts** — funded Hedera accounts that pay for and execute a policy's on-chain transactions, so costs can be isolated per project instead of per user.
