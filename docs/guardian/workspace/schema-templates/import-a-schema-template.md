# Import a Schema Template

Import a schema template to reuse its schemas and restrictions. See [Schema Templates Concept](./).

### Prerequisites

* You are signed in as a Standard Registry user.
* You can manage schema templates.
* You have a compatible template import file or message.

### Steps

1. Open the **Schema Templates** grid.
2. Select **Import**.
3. Provide the template import source.
4. Review the imported template configuration and schemas.
5. Confirm the import.

### Result

The template appears in the grid as an independent schema template entity.
