# Getting Started

Choose the path that matches your experience and operating needs.

### Try Guardian without operating infrastructure

Use the [Managed Guardian Service](https://guardianservice.io) for a hosted Guardian environment.

Choose this option if you do not want to install or operate infrastructure.

### Run open-source Guardian

[Open-source releases](https://github.com/hashgraph/guardian/releases) are available on GitHub.

Choose one of these paths:

* **Docker containers** — Suitable for users comfortable running and configuring services.
* **Build from source** — Suitable for contributors and teams needing custom changes.

Building from source requires more time and operational knowledge. You manage dependencies, configuration, upgrades, and the running environment.

The [Guardian repository README](https://github.com/hashgraph/guardian#readme) is the source of truth for supported releases, commands, and configuration.

### Ready to install?

Continue to the [Installation Guide](guardian/readme/getting-started/) to choose a self-hosted installation path.
